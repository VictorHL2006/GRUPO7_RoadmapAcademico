# Módulo Motor de Recomendación
Procesa la malla curricular y el historial estudiantil para calcular la prioridad de cursos, el balance de carga académica y la especialidad recomendada.
Ejecución de pruebas: `pytest -q`
Ejemplo de salida:
`{"estudiante": "E001", "especialidad": "Redes y Seguridad", "puntajes": {"Redes y Seguridad": 2}, "cursos": ["MAT102", "PRG102"], "creditos": 8}`
